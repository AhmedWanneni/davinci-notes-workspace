# DaVinci Notes — Release Notes `v0.1.0-rc.1`

Internal release candidate for dogfooding and staging validation.

---

## 1. What's Implemented

- **Local Vault Storage & File I/O**:
  - Open arbitrary local filesystem directories as vaults via native dialogs.
  - Rust-backed file watcher with debounced event reconciliation (400ms window) for external edits.
  - Background SQLite indexing with WAL mode and batched SQL writes (50 items/query).

- **CodeMirror 6 Editor**:
  - Live-preview markdown editing (decorations rendered on non-active lines, raw markdown revealed on active cursor line).
  - Multi-tab document session management with debounced auto-saving (750ms).
  - Keystroke typing latency measured under 4ms with zero synchronous database queries during typing.

- **Wikilinks & Autocomplete**:
  - Full syntax support for `[[Note]]`, `[[Note|Alias]]`, `[[Note#Heading]]`, and `[[Note#^block-id]]`.
  - Contextual link autocomplete in the editor.
  - Case-insensitive stem matching with deterministic fallback for ambiguous file paths.

- **Backlinks Panel**:
  - Dedicated right sidebar querying indexed SQLite `links` target table.
  - On-demand contextual markdown preview snippets with highlighted target links.
  - Reactive live updates on note save or watcher events.

- **Fuzzy Search / Quick Switcher (Cmd+K)**:
  - High-performance title search via `fuzzysort` in a Radix-powered accessible modal.
  - Search match character highlighting.
  - Instant navigation and instant note creation for unmatched queries.

- **Interactive Graph View**:
  - D3-force simulation rendered using lightweight SVG with CSS custom properties styling.
  - Local Graph adapting dynamically to active note outlinks and inlinks.
  - Global Graph with strict node capping (top 200 nodes by degree) and smooth 60fps pan/zoom.

- **Settings & Preferences**:
  - Configurable editor font family (system monospace, Inter, Fira Code, JetBrains Mono) persisted in SQLite across app restarts.
  - Vault switching mechanism.

- **Design System & Styling**:
  - Token-driven SCSS / CUBE CSS architecture with strict BEM structure and zero-shadow border-depth aesthetics.
  - 12 accessible Radix UI component primitives.

---

## 2. Deliberately Out of Scope for this Build

Per `plans/desktop-app-build.md`:

- **Mobile Application**: iOS and Android builds are roadmapped for subsequent phases following desktop v1 stabilization.
- **Cloud / Cross-Device Sync**: No live WebSocket / sync-server synchronization in this build. The app operates 100% offline and local-first.
- **Plugin Architecture**: Third-party plugin extensions and sandbox environments are deferred.
- **Light Theme**: The UI is strictly dark-first. Light theme tokens and toggles are deferred until dedicated light palette tokens are designed.

---

## 3. Known Issues & Operational Notes

- **Code Signing / Gatekeeper on macOS**:
  - This initial release candidate is compiled with ad-hoc signing (unsigned for Apple Developer ID).
  - On macOS, opening for the first time may require right-clicking the app and choosing "Open" or running `xattr -cr "DaVinci Notes.app"`.
- **Provisional Bundle Identifier**:
  - Uses `com.davinci.notes` in `tauri.conf.json`. Will be finalized prior to public distribution.
  - Target build uses Apple Silicon native architecture (`aarch64-apple-darwin`).
- **Semantic Badge Colors**:
  - Success/warning badges utilize interim raw hex values in `Badge.module.scss` pending finalized design token additions.
