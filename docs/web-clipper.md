# Web Clipper — User & Architecture Guide

The DaVinci Notes Web Clipper is a privacy-first browser extension for Chromium (Chrome, Edge, Brave, Arc) and Firefox that clips web articles, selections, and highlights directly into your local DaVinci Notes vault as Markdown notes.

---

## 1. Privacy & Security Model

The Web Clipper is strictly local-first and zero-cloud:

- **No Remote Servers**: Content never leaves your computer. The extension communicates exclusively with the local DaVinci Notes desktop app over an encrypted loopback connection (`http://127.0.0.1:<port>`).
- **Token Authentication**: Every write requires a cryptographically random, per-installation bearer token generated by DaVinci Notes and stored in the extension's secure local storage.
- **SSRF & Attack Surface Hardening**:
  - The desktop listener binds strictly to `127.0.0.1` and rejects foreign `Host` or `Origin` headers.
  - Attachment image downloads are executed natively with strict SSRF protections that reject loopback, link-local, carrier-grade NAT, private LAN, cloud metadata endpoints (`169.254.169.254`), and non-image content.
  - The desktop re-validates all incoming paths and folders, rejecting traversal attempts (`../`) and illegal characters rather than blindly trusting the browser.

---

## 2. Pairing with DaVinci Notes

To pair the extension with your desktop application:

1. Open **DaVinci Notes** on your computer.
2. Go to **Settings** (`Cmd/Ctrl+,`) → **Web Clipper**.
3. Toggle **Enable Web Clipper**. The panel will display your local **Port** (e.g. `47912`) and **Pairing Token**.
4. In your browser, open the DaVinci Notes Web Clipper **Options** page (right-click the extension icon → **Options**).
5. Paste the Port and Token into the fields and click **Save pairing**.

> **Offline / Unpaired Fallback**: If DaVinci Notes is closed or unpaired, you can still clip any page and click **Download .md** to save the note directly to your downloads folder.

---

## 3. Clipping Modes

The extension supports three clipping modes:

| Mode | Description |
|---|---|
| **Full page** | Extracts the clean article content using Defuddle and Turndown, stripping navigation, ads, and footers while preserving code blocks, LaTeX math, and callouts. |
| **Selection** | Clips only the currently highlighted text on the page. Enabled whenever you have text selected. |
| **Highlights** | Clips all persistent text highlights saved on the current URL. |

---

## 4. Highlighter

You can highlight key passages on any webpage:
- Select text on a page, open the clipper popup, and click **Highlight selection** (or press `Alt+Shift+H`).
- Highlights are stored locally per URL in `chrome.storage.local`.
- When you revisit the page, highlights are restored cleanly without layout shift or external network calls.
- In templates, highlights can be rendered as inline `==highlight==` blocks or blockquotes using the `highlight` filter.

---

## 5. Templates & Auto-Apply

The Web Clipper includes a flexible templating engine:

- **Starter Templates**: Shipped with **Article**, **Recipe**, and **Blank** templates.
- **Variables**: Interpolate metadata such as `{{title}}`, `{{url}}`, `{{author}}`, `{{published}}`, `{{body}}`, `{{site}}`, and `{{wordCount}}`.
- **CSS Selectors & Schema.org**: Extract custom fields directly from page elements (`selector:.price`) or structured JSON-LD data (`schema:recipeIngredient`).
- **Auto-apply Rules**: Configure URL regexes, domain rules, or Schema.org types so the right template activates automatically when a matching page loads.
- **Offline Images**: Toggle **Save images to vault** in any template to automatically download remote article images into your vault attachments folder and rewrite links to offline relative paths.

---

## 6. Closed-App Queue & Dedupe

If DaVinci Notes is closed when you clip:

- The clip is safely buffered in the extension's offline queue (capped at 200 clips / 5 MiB with oldest-first eviction).
- When DaVinci Notes opens, the extension automatically drains queued clips in the background on browser startup or when the popup opens.
- The desktop maintains a ring-buffer dedupe ledger (`davinci-clipper-ledger.json`, 500 entries) preventing duplicate note creation if a clip is retried or resent.

---

## 7. Keyboard Shortcuts

Default shortcuts (customizable via `chrome://extensions/shortcuts`):

- `Alt+Shift+C`: Open the Clipper popup.
- `Alt+Shift+S`: Headless Quick-Clip (instantly clips the active tab using the best-matching template without opening the popup).
- `Alt+Shift+H`: Toggle highlighter for current selection.
