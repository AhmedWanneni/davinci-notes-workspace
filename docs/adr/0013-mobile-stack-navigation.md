# ADR-0013: Mobile navigation is stack-based, not multi-pane

## Status
Accepted

## Context
Desktop's multi-pane/split-view model doesn't translate to a phone screen.

## Decision
Use stack-based navigation on mobile. Backlinks/graph/tags become sheets or dedicated screens rather than always-visible panels.

## Consequences
- No multi-pane UI on mobile; navigation mirrors native mobile conventions.
