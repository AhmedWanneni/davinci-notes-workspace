# @app/design-system

## 0.1.0

### Minor Changes

- Initial release of `@app/design-system` (reconstructed from Phases 1–3 and Phase 12 session logs):

  - **Tokens Engine**: Style Dictionary build pipeline generating SCSS variables, CSS custom properties, and typed TypeScript constants from tokens (`color`, `type`, `space`, `border`, `motion`, `icon`).
  - **Foundations**: Swiss/Editorial-inspired dark aesthetic, CSS reset, global mixins (`border-depth`, `focus-visible`, `breakpoints`), and zero-shadow border-depth styling.
  - **12 Component Primitives**: Fully tested and Storybook-documented primitives (Typography, Button, Input, Checkbox, Radio, Toggle, Divider, Badge, Tooltip, Dialog, DropdownMenu, Popover) backed by accessible Radix UI primitives.
  - **CUBE CSS & Token Alignment**: Native CSS custom properties integration and Stylelint token enforcement.
